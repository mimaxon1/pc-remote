## Short description

## Description

PC Remote is a lightweight, open-source remote controller for Windows.

Run PC Remote on your computer, pair your phone with a QR code, and use the phone's browser as a local control panel. No separate mobile app, external account, subscription, or developer-operated cloud service is required.

PC Remote can control system volume and mute, media playback, audio output devices, desktop applications, application windows, and Windows power actions. It includes light and dark themes and supports both English and Russian.

The application is local-first: normal control traffic stays between your PC and the paired browser on the same Wi-Fi or LAN. PC Remote is intended for trusted local networks and should not be exposed directly to the public internet.

Typical uses include couch/HTPC control, media PCs connected to a TV, presentation and demo systems, local gaming/streaming setups, and a second-screen control panel.

Source code and documentation are available on GitHub under the Apache License 2.0.

## Screenshot plan

At least one screenshot is required for a Store submission; four or more are recommended. Capture real application UI rather than mockups.

Recommended set:

1. Windows tray/status or pairing window with QR code visible.
2. Phone browser main controller showing the primary controls.
3. Application/window control screen.
4. Media/audio control screen.
5. Dark theme or another secondary screen.

Do not include private IP addresses, personal notifications, account names, tokens, PINs, or other sensitive data in screenshots.
