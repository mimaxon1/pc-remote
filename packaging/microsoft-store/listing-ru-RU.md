## Название

PC Remote

## Краткое описание

Управляйте Windows-компьютером с любого телефона через браузер в той же локальной сети. Без мобильного приложения, аккаунта и облака.

## Описание

PC Remote — лёгкий open-source пульт для Windows.

Запустите PC Remote на компьютере, подключите телефон по QR-коду и используйте браузер телефона как локальную панель управления. Отдельное мобильное приложение, внешний аккаунт, подписка или облачный сервис разработчика не требуются.

PC Remote позволяет управлять системной громкостью и mute, мультимедиа, устройствами аудиовыхода, запуском приложений, окнами приложений и действиями питания Windows. Есть светлая и тёмная темы, интерфейс на русском и английском языках.

Приложение построено по local-first принципу: обычный управляющий трафик идёт напрямую между ПК и подключённым браузером в одной Wi-Fi/LAN сети. PC Remote рассчитан на доверенную локальную сеть и не должен напрямую публиковаться в интернет.

Подходит для управления компьютером с дивана, HTPC и медиа-ПК у телевизора, презентаций и демонстрационных систем, локального игрового/стримингового ПК и второго экрана управления.

Исходный код и документация опубликованы на GitHub по лицензии Apache License 2.0.

## Возможности

В Partner Center не добавляйте символы маркеров — список отображается автоматически.

1. Управление Windows из современного браузера телефона
2. Подключение по QR-коду в локальной сети
3. Не требуется мобильное приложение или внешний аккаунт
4. Не требуется облачный backend разработчика
5. Громкость, mute и управление мультимедиа
6. Выбор устройства аудиовыхода
7. Запуск недавних и закреплённых приложений
8. Открытие, сворачивание и закрытие окон
9. Действия питания Windows
10. Светлая и тёмная темы
11. Русский и английский интерфейс
12. Открытый исходный код по Apache License 2.0

## План скриншотов

Для публикации нужен минимум один реальный скриншот приложения; лучше подготовить четыре или больше.

Рекомендуемый набор:

1. Окно PC Remote в Windows с подключением по QR-коду.
2. Главный экран контроллера в браузере телефона.
3. Экран управления приложениями и окнами.
4. Экран мультимедиа и аудио.

Перед съёмкой скрыть личные IP-адреса, уведомления, имена учётных записей, токены, PIN-коды и другие чувствительные данные.
