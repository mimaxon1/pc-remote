# История изменений

[English](CHANGELOG.md) · **Русский**

## Не выпущено

- автоматические тесты перенесены в отдельный каталог `tests/`
- дополнительная документация собрана в `docs/`, публичные документы упрощены
- добавлены GitHub Actions, шаблоны issues и pull requests
- README переработан под публичную страницу проекта

## v1.4.1

- усилен rate limiting входа: добавлен `Retry-After` и более понятная обратная связь при временной блокировке PIN
- восстановление web-сессии стало устойчивее после обновления страницы, кратковременной недоступности API и повторного подключения
- нормализована обработка путей приложений, включая пути в кавычках и дубликаты закреплённых приложений
- улучшена очистка истёкших QR-токенов и обработка ошибок записи настроек
- улучшен просмотр логов в трее и уменьшен размер сборки за счёт исключения ненужных optional-модулей

## v1.4.0

- добавлены быстрые действия с приложениями: запуск, сворачивание и закрытие
- добавлены закреплённые приложения рядом с недавними
- улучшен поиск и запуск обычных приложений, ярлыков и packaged Windows apps
- добавлены светлая и тёмная темы web-интерфейса
- добавлено переключение русского и английского языка
- улучшен перезапуск и завершение GUI при сбросе настроек
- расширены тесты приложений, завершения GUI и API web-контроллера

## v1.3.5

- web-контроллер получил адаптивный retry/backoff вместо постоянного опроса при недоступном API
- версия приложения и параметры повторного подключения добавлены в runtime config и `/health`
- локальные каталоги `build*` и `dist*` исключены из будущих коммитов
- документация обновлена под состояние после `v1.3.4`

## v1.3.4

- исправлена подпись QR-окна: теперь отображается полный pairing URL с токеном
- снижена нагрузка контроллера за счёт фонового кэширования системной информации и инкрементального обновления логов
- tray, QR, imaging и audio-зависимости переведены на lazy loading для более быстрого запуска packaged-версии
- добавлен helper для release-сборки с возможностью очистки локальных настроек

## v1.3.3-preview

- добавлен кэш системной информации с TTL для уменьшения количества дорогих вызовов
- ответы системной информации изолированы от вызывающего кода через defensive copies
- добавлены тесты повторного использования, истечения TTL и безопасности копий

## v1.3.0

- исправлен запуск API в packaged `.exe` без консоли
- отключён лишний stderr-лог `SimpleHTTPRequestHandler` в packaged web-сервере
- `settings.json` перенесён в `%APPDATA%\PC Remote\settings.json`
- добавлена миграция со старого расположения `settings.json` рядом со скриптом или exe
- сетевые интерфейсы в web UI теперь выводятся по одному на строку

## v1.1.0

- усилен первый QR/PIN setup
- смена PIN заблокирована до завершения первичной настройки
- удалён тихий fallback на дефолтный PIN при повреждённом `settings.json`
- QR-окно трея закрывается только после завершения pairing flow
- локальные обращения tray → API переведены на `127.0.0.1`
- `os.chdir()` удалён из потока web-сервера
- улучшена обработка быстрых изменений громкости

## v1.0.0

- первая публичная версия
