# AlternativeTo submission

Name: PC Remote

Website: https://mimaxon1.github.io/pc-remote/

Source: https://github.com/mimaxon1/pc-remote

Download: https://github.com/mimaxon1/pc-remote/releases/latest

License: Free, open source, Apache-2.0

Desktop platforms: Windows, macOS. Phone controller: Android/iPhone browser (no native mobile app).

Category: Mobile Remote Control

Summary: Control your PC or Mac from any phone browser. Volume, media and apps over local Wi-Fi, with QR pairing and no mobile app or cloud account.

Description:

PC Remote turns your Android or iPhone browser into a local remote for a Windows PC or Mac. Run the desktop app, scan its pairing QR code, and control your computer over the same Wi-Fi/LAN.

Use it to adjust volume, mute sound, control media playback, launch recent or pinned apps, manage application windows and use available power actions. The interface supports English and Russian, with light and dark themes.

PC Remote is free and open source under Apache 2.0. Ready-made Windows installer/portable builds and a universal macOS app are available. No mobile app or cloud account is needed.

It is a focused alternative for people who want everyday controls from the couch. It does not provide screen sharing, mouse/keyboard emulation or Bluetooth. Mac media controls target Music, and some actions require macOS permissions. It is intended for a trusted local network, not direct internet exposure.

Suggested alternative: Unified Remote, for volume/media/app-control use cases.

Features: Browser-based, No registration required, Ad-free, Dark Mode, Lightweight, Local network, Open Source.
