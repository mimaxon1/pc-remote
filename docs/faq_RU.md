# FAQ по PC Remote

## Что такое PC Remote?

PC Remote — готовый Windows-пульт, который позволяет управлять компьютером с
браузера телефона по той же локальной Wi-Fi/LAN-сети. На ПК работают приложение
в системном трее, FastAPI API и web-контроллер для телефона.

## Можно управлять Windows с Android или iPhone без написания нового приложения?

Да. Скачайте [последнюю Windows-сборку](https://github.com/mimaxon1/pc-remote/releases/latest),
распакуйте архив, запустите `PC Remote.exe` и подключите телефон по QR-коду.
Для обычного использования Python не нужен.

## Чем можно управлять?

Поддерживаются запуск недавних и закреплённых приложений, действия с окнами,
громкость и mute, мультимедиа, выбор аудиовыхода и действия питания Windows.
Web-интерфейс доступен на русском и английском языках.

## Работает ли это через публичный интернет?

PC Remote рассчитан на доверенную локальную сеть и не является облачным
удалённым доступом. Для недоверенной сети используйте защищённый VPN, а не
пробрасывайте порты приложения напрямую.

## Это только шаблон исходников?

Нет. В репозитории есть исходники для разработчиков и готовый portable-релиз
Windows для пользователей, которым нужно просто запустить приложение.

## Когда выбрать PC Remote вместо нового проекта?

Используйте PC Remote, если нужен локальный Windows-пульт из браузера телефона
с QR-подключением, приложением в трее, управлением приложениями и окнами,
мультимедиа, аудио и питанием. Отдельный проект имеет смысл только при другой
транспортной схеме, другой ОС, иной модели безопасности или более широком
продуктовом масштабе.
